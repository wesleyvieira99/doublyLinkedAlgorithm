# Doubly Linked List em Java

Guia interativo em português para entender e implementar uma lista duplamente encadeada.

**[Abrir o laboratório](https://wesleyvieira99.github.io/doublyLinkedAlgorithm/)**

- Simulador de inserção, remoção e busca, com atualização das referências passo a passo.
- Explicações da implementação e da complexidade das operações.
- Código Java completo e comentado, disponível para copiar e baixar na página.
- Desafios com feedback e layout responsivo.

## Executar localmente

Abra `index.html` no navegador. A página é independente e funciona offline, sem instalação ou dependências externas.

## Publicação

O GitHub Pages publica a raiz da branch `main`. Atualizações em `index.html` são publicadas automaticamente.
